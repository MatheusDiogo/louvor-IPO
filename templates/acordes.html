Grafias

Como a equipe escreve o tipo do acorde depois da nota. Ex.: 4/7 = 7sus4 faz A4/7, B4/7... funcionarem em todas as músicas.

Variações de escrita já são reconhecidas sozinhas, então cada grafia aparece uma vez só: 7(9) = 7/9 = 79; m7(5-) = m7(b5) = m7b5; maj7 = Δ = 7M; sus4 = 4; 5+ = #5; dim = m5-; °7 = °.

O significado segue o padrão de cifragem do Cifra Club: C9 = add9, C11 = tríade + 11ª, Cm5- = diminuto, C° = diminuto com sétima, C5 = power chord. Para a equipe usar outro significado, cadastre a grafia de novo com o tipo desejado.
